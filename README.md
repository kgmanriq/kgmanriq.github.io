# kgmanriq.github.io

Personal site for Katrina Manrique, built with Jekyll and hosted on GitHub Pages.
Live at **https://kgmanriq.github.io**.

## What's here

- `index.html`: the landing page (name, contact line, overview)
- `_layouts/default.html`: the shared page template (sidebar + content column)
- `assets/css/style.css`: all styling; colors and fonts are the variables at the top
- `_config.yml`: name, email, LinkedIn, and the sidebar's page list

Earlier versions of the site (projects, resume, blog) are in this repo's commit history if you want to bring any of it back.
